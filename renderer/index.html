Claude LinGUI

A graphical front end for Claude Code. Pick a working directory, choose a model, and start talking.

Sends messages to a cloud session that already exists — replies show up on claude.ai/code or the mobile app, not here (the CLI only lets this window queue messages, not watch the conversation). To start a new session, run claude --cloud "description" in a terminal, or create one from claude.ai/code — then paste its ID or URL here.
